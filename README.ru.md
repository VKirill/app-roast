# App Roast

**Приложение пишет «Сохранено». А оно, блядь, сохранило?**

Навык для кодинговых агентов: искать противоречия между обещаниями продукта, интерфейсом, фактическим поведением, API и кодом. Сначала доказательства и технический разбор, затем прожарка конкретных косяков.

[English](README.md) · [Инструкции навыка](skills/app-roast/SKILL.md) · [Пример документа](examples/report.ru.md)

## Установка

```sh
npx skills add VKirill/app-roast --skill app-roast
```

Либо положите папку `skills/app-roast/` в каталог навыков вашего агента. Если навыки управляются через общий хаб, опубликуйте папку туда. Python 3 нужен только для необязательного скрипта создания отчёта. GitNexus и конкретный браузерный инструмент не обязательны.

## Как вызвать

```text
Используй app-roast для этого приложения.
Пройди основные пользовательские сценарии и проверь их по коду.
Особенно ищи противоречия между надписями, действиями, сохранёнными данными,
API, состояниями на разных экранах, отменой и повторными попытками.
Язык: русский. Тон: brutal, с матом.
Веди документ по ходу работы. Пока только аудит, без исправлений.
Если GitNexus доступен и подходит для репозитория — используй его.
```

## Что останется после работы

> [!IMPORTANT]
> Агент создаёт документ до начала проверки и дописывает его по мере работы. Прерывание сессии не должно уничтожать найденные проблемы и план продолжения.

В `.agents/app-grill/<запуск>/report.md` в корне проверяемого проекта будут:

- Цель, условия проверки и ваши инструкции.
- Иерархия задач: область → сценарий → проверка, со статусами.
- Карта обещаний и фактических результатов.
- Карточки находок: ожидание, факт, воспроизведение, доказательства, последствия.
- Отдельные разделы для гипотез и субъективных UX-замечаний.
- Прожарка со ссылками на конкретные находки.
- План исправлений с зависимостями и проверкой результата.
- Покрытие, ограничения, история решений и точка продолжения.

Каждый запуск получает отдельную папку с датой и именем приложения. Доказательства сохраняются рядом в `evidence/`: очищенные от секретов логи, ответы API, скриншоты и другие материалы. Для проверки по URL без локального проекта используется корень рабочего пространства. Явно заданный путь отчёта имеет приоритет. Исправления агент делает, только если это входит в ваш запрос.

## Профессиональный разбор под матерной обложкой

| Статус | Что означает |
| --- | --- |
| `CONFIRMED-RUNTIME` | Несостыковка наблюдалась при выполнении сценария |
| `CONFIRMED-CODE` | Противоречие доказано по достижимому пути кода; выполнение не проверено |
| `HYPOTHESIS` | Не хватает доказательств; записан следующий шаг проверки |
| `UX-JUDGMENT` | Аргументированная оценка удобства, а не доказанный функциональный баг |
| `REJECTED` | Подозрение проверено и опровергнуто либо поведение соответствует условиям |

GitNexus помогает найти связи между интерфейсом, обработчиком и хранилищем. Его граф не заменяет чтение кода. **Если индекс отстаёт, агент сам обновляет его и проверяет актуальность перед использованием**, в том числе в режиме аудита без исправлений. Обновляются производные данные индекса; код приложения и файлы инструкций не переписываются. Если инструмента нет либо обновление действительно заблокировано или завершилось ошибкой, агент записывает причину в отчёт и продолжает поиск по текущему коду.

Тон `professional` даёт нейтральный инженерный отчёт, `roast` — сарказм, `brutal` — жёсткую прожарку с матом. Технические карточки остаются точными. Людей не оскорбляем, баги ради шутки не выдумываем, «всё приложение проверено» после трёх кликов не объявляем.

Необязательный скрипт создаёт английскую заготовку: `--language` записывает язык итогового отчёта в метаданные, а агент переводит и адаптирует содержимое. В `professional` шуток и мата нет ни в карточках, ни в итоговой оценке.

До создания отчёта скрипт проверяет возможность записи в `evidence/`. При конфликте или отказе записи он возвращает понятную ошибку без нового блокирующего отчёта. Существующие документы и пользовательские файлы сохраняются.

Чтобы продолжить проверку, укажите существующий `report.md`: агент сохранит IDs, доказательства и историю. [Проверки и ограничения валидации](evals/README.md). Лицензия MIT.
